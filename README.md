## 🏗️ Featured Project

### SIHASOFT — Secure Medical SaaS Platform

A secure SaaS platform designed for **dental clinics and patient journey digitalization**.

The platform is based on:

* 🏢 Multi-tenant architecture
* 🔐 Secure authentication and role-based access control
* 🧬 Biometric authentication
* 📱 Mobile patient experience
* 📄 Cryptographic document verification
* 🔎 QR Code document verification
* 🩺 Patient and clinic management
* 📊 Administrative dashboards
* 🔄 REST APIs

**Stack:** Django · Django REST Framework · PostgreSQL · Next.js · React · Flutter · JWT · RBAC
